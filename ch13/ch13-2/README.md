# 실습과제 1
1. C언어에서 문자를 메모리에 저장하는 방식에 대하여 설명하라(아스키 코드 참고)

  -> C언어에서 문자는 아스키 코드와 같은 문자 코드에 대응하는 정수값으로 메모리에 저장된다.
  
  ex) `'A'`는 아스키 코드값으로 65로, `'a'`는 아스키 코드값으로 97로 저장되며 저장된 값은 문자나 정수 형태로 출력할 수 있다.

2. 널문자의 용도를 설명하라.

  -> 널문자는 문자열의 끝을 나타내는 문자로 문자열의 길이나 끝은 판단하는데 사용된다.

3. 메모리에 저장된 문자열의 끝을 찾는 방법을 설명하라.

  -> 문자열의 처음부터 문자를 하나씩 검사하여 널문자를 찾고 널문자가 저장된 위치를 문자열의 끝으로 판단한다. 

4. 문자열의 길이를 구하는 알고리즘을 설명하라.

  -> 반복문을 이용하여 문자열의 문자를 하나씩 검사하고 널문자를 만날 때까지 문자의 개수를 세어 문자열의 길이를 구한다.

# 실습과제 2
## 작성한 코드 설명
```
#define _CRT_SECURE_NO_WARNINGS
```
- 보안관련 경고 방지
```

```
- 리턴값관련 경고 방지
```
#include<stdio.h>
```
- 헤더파일 stdio.h를 포함해라
```
int main(void)
```
- 메인함수 시작
```
int i;
```
- int형 변수 i 선언
```
char str[100];
```
- 문자 배열 str 선언
```
printf("문자열을 입력하시오: ");
```
- 사용자에세 문자열을 입력하라는 안내 문구 출력
```
scanf("%s", str);
```
- 키보드로 입력한 문자열을 `str`배열에 저장
  *여기서 `&str`을 쓰지 않는 이유는 배열 이름 `str`자체가 배열의 첫 번째 요소의 주소를 나타내기 때문
```
for (i = 0; str[i] != '\0'; i++)
{
  printf("%d번째 문자: %c\n", i + 1, str[i]);
}
```
- `for (i = 0; str[i] != '\0'; i++)`: `i`를 0부터 시작해서 `str[i]`가 널문자가 아닐 때까지 반복
- `printf("%d번째 문자: %c\n", i + 1, str[i]);`: 현재 문자의 순서와 문자 자체 출력
```
return 0;
```

```
#define _CRT_SECURE_NO_WARNINGS
```
- 보안관련 경고 방지
```
#pragma warning(disable:6031)
```
- 리턴값관련 경고 방지
```
#include<stdio.h>
```
- 헤더파일 stdio.h를 포함해라
```
int main(void)
```
- 메인함수 시작
```
int i;
```
- int형 변수 i 선언 
```
char str[100];
```
- 문자 배열 str 선언
```
printf("문자열을 입력하시오: ");
```
- 사용자에게 문자열을 입력하라는 안내 문구를 출력
```

```
- 사용자가 입력한 문자열을 `str` 배열에 저장
```
for (i = 0; str[i] != '\0'; i++)
```
- `i`를 0부터 시작해서 널문자를 만날 때까지 문자열의 문자를 하나씩 검사
```
  if (str[i] >= 'A' && str[i] <= 'Z')
    str[i] += 32;
```
- `if (str[i] >= 'A' && str[i] <= 'Z')`: 현재 문자인 `str[i]`가 대문자인지 확인
- `str[i] += 32;`: 대문자를 소문자로 변환
```
	else if (str[i] >= 'a' && str[i] <= 'z')
    str[i] -= 32;
```
- `else if (str[i] >= 'a' && str[i] <= 'z')`: 앞의 if문의 조건이 거짓일 경우 현재 문자가 소문자인지 확인
- `str[i] -= 32;`: 소문자를 대문자로 변환
```
printf("변환 결과: %s", str);
```
- 변환이 끝난 문자열 전체를 출력
```
return 0;
```

```
#define _CRT_SECURE_NO_WARNINGS
```
- 보안관련 경고 방지
```

```
- 리턴값관련 경고 방지
```
#include<stdio.h>
```
- 헤더파일 stdio.h를 포함해라
```
int main(void)
```
- 메인함수 시작
```
char str1[100];
```
- 문자 배열 str1 선언
```
char str2[100];
```
- 문자 배열 str2 선언
```
printf("문자열을 입력하시오: ");
```
- 사용자에게 문자열을 입력하라는 메시지 출력
```
scanf("%s", str1);
```
- 사용자가 입력한 문자열을 `str1`에 저장
```
printf("문자열을 입력하시오: ");
```
- 사용자에게 문자열을 입력하라는 메시지 출력
```
scanf("%s", str2);
```
- 사용자가 입력한 문자열을 `str2`에 저장
```
if (str1[0] < str2[0])
  printf("사전에서 앞에 나오는 문자열: %s", str1);
```
- `if (str1[0] < str2[0])`: `str1`과 `str2`의 첫 번째 문자 비교
- `printf("사전에서 앞에 나오는 문자열: %s", str1);`: `str1`의 첫 번째 문자가 더 작다면 `str1`이 사전에서 앞에 나온다고 판단하고 `str1`을 전체 출력
```
else if (str1[0] > str2[0])
  printf("사전에서 앞에 나오는 문자열: %s", str2);
```
- `else if (str1[0] > str2[0])`: 반대로 `str1`의 첫 번째 문자가 `str2`의 첫 번째 문자보다 크면 실행
- `printf("사전에서 앞에 나오는 문자열: %s", str2);`: 이 경우 `str2`이 사전에서 앞에 나온다고 판단하고 `str2`을 전체 출력
```
return 0;
```

# 실습과제 5
## 작성한 코드 설명
```
#include<stdio.h>
```
- 헤더파일 stdio.h를 포함해라
```
int main(void)
```
- 메인함수 시
```
char* fruits[] = { "apple","blueberry","orange","melon" };
```
- 여러개의 문자열을 저장하는 포인터 배열 fruits를 선언하고 apple, bluseberry, orange, melon을 저장
```
int i;
```
- int형 변수 i 선언
```
int min = 0;
```
- int형 min을 선언하고 0을 저장
```
for (i = 1; i < 4; i++)
```
- i를 1부터 3까지 증가시키면서 문자열을 하나씩 비교
```
  if (fruits[i][0] < fruits[min][0])
    min = i;
```
- `if (fruits[i][0] < fruits[min][0])`: `fruits[i][0]`은 i번째 문자열의 첫 번째 문자를 의미하고 `fruits[min][0]`은 현재 가장 앞에 있다고 판단한 문자열의 첫 번째 문자이다. 따라서 처음에는 'b','o','m'을 'a'와 비교함
- `min = i;`: 현재 비교한 문자열의 첫 번째 문자가 기존의 문자보다 작다면 `min`에 현재 문자열의 인덱스 저장
```
printf("사전에서 가장 앞에 나오는 문자열: %s", fruits[min]);
```
- `min`에 저장된 인덱스를 이용해서 가장 앞에 있다고 판단된 문자열 전체를 출력
```
return 0;
```
- 0을 반환하고 메인함수 종
