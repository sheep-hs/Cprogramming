# 실습과제 1
1. 배열명의 의미를 설명하라.

  -> 배열 첫번째 요소의 주소이다.
  
2. 배열표현과 포인터(주소) 표현의 변환 공식을 설명하라.
  | 구분 | 배열표현 | 포인터(주소) 표현 |
  | :--- | :--- | :--- |
  | 배열요소의 값 | `a[i]` | `*(a+i)` |
  | 배열요소의 주소 | `&a[i]` | `a+i` |
  
3. 배열의 첫번째 요소의 주소만 알면 모든 원소의 주소를 계산할 수 있다. 방범을 설명하시오.

  -> 배열의 모든 요소는 메모리에 연속적으로 저장된다. 배열의 첫 번째 요소의 주소에 자료형의 크기와 원      소의 인덱스를 곱한 값을 더하여 각 원소의 주소를 계산할 수있다.

4. 배열의 첫번째 요소의 주소만 알면 모든 원소의 값을 계산할 수 있다. 방법을 설명하시오.

  -> 배열의 첫 번째 요소의 주소에 인덱스와 자료형의 크기를 이용하여 원하는 요소의 주소를 구한 후 해당   주소의 값을 간접참조하여 원소의 값을 계산할 수 있다.
  
5. 포인터에 대해 가능한 연산의 종류와 의미를 설명하라.
  - 간접참조(`*`): 포인터가 가리키는 주소에 저장된 값을 읽거나 쓰는 연산자 
  - 정수 덧셈(`+`): 포인터가 현재 가리키는 주소에서 자료형의 크기 x n 만큼 앞로 이동
  - 정수 뺄셈(`-`): 포인터가 현재 가리키는 주소에서 자료형의 크기 x n 만큼 뒤로 이동 
  - 증감(`++`, `--`): 가리키는 자료형의 크기만큼 포인터가 다음 요소의 주소로 이동 
  
6. 포인터 연산을 기존의 산술연산과 다르게 정의한 이유는 무엇일까?

  -> 포인터는 메모리 주소를 저장하므로 포인터에서 정수 값을 더하거나 뺄 때 자료형의 크기를 고려하려 
    다음 또는 이전 메모리 위치로 이동할 수 있도록 하기 위해 기존의 산술연산과 다르게 정의하였다.

```
#include<stdio.h>
int main(void)
{
  int grade[5];
  int sum = 0, i, average;
  for(i= 0; i< 5; i++)
  {
    printf("성적을 입력하시오: ");
    scanf("%d", &grade[i]);
  }
  for(i= 0; i< 5; i++)
    sum += grade[i];
  average = sum / 5.0;
  printf("성적 평균= %d\n", average);
  return0;
}
```

# 실습과제 3
## 증감연산자 a++, ++a의 차이를 설명하시오.
   - a++(후위 증감연산자): 현재 값을 먼저 사용한 후 값을 1만큼 증가시킨다.
   - ++a(전위 증감연산자): 값을 먼저 1만큼 증가시킨 후 증가된 값을 사용한다.
## 문제에 주어진 코드
```
#include<stdio.h>
  int main(void)
{
  int a[] = { 10, 20, 30 }, i, sum = 0;
  for (i = 0; i < 3; i++)
    sum += *a++;
  printf("sum:%d\n", sum);
  return0;
}
```

## 코드의 문제점
배열 이름은 주소를 나타내지만 그 자체를 변경할 수 없으므로 `a++`와 값은 포인터 연산을 수행할 수 없다. 따라서 포인터 변수를 선언하여 배열의 주소를 저장한 후 포인터 연산을 해야한다.

```

```

```

```

```

```

