# 실습과제 1
1. 16MB 메모리의 주소의 범위를 구하시오
   
-> 1MB는 2^20바이트로 16MB 메모리는 16*2^20 바이트 즉 2^24바이트로 총 2^24개의 주소가 필요하다. 그러므로 16MB 메모리의 주소의 범위는 0~2^24-1이다.

2. 변수의 주소를 설명하시오.

-> 변수의 주소는 변수가 차지하고 있는 공간의 시작 번지(가장 작은 주소)이다.

3. 변수의 주소의 자료형은 무엇인가?

-> 변수의 주소의 자료형은 (주소가 가리키는 변수의 자료형)* 이다.

4. 포인터란 무엇인가?

-> 포인터란 주소를 저장하기 위한 변수이다.

5. 포인터의 자료형은 무엇인가?

-> 포인터의 자료형은 포인터의 저장될 주소의 자료형(자료형*) 이다.

6.  변수의 주소를 int형 변수에 저장하면 어떻게 되는가?

-> 변수의 주소는 일반적인 문자, 정수 ,실수와는 다른 새로운 자료형으로 변수의 주소를 int형 변수에 저장하게 되면 주소를 저장하는 것이 아닌 정수로 저장하게 되므로 주소를 저장할 때에는 int형 변수가 아닌 포인터 변수를 사용해야 한다.

# 실습과제 2
```
double * pt;
```
1. 다음에서 pt가 가리키는 데이터의 자료형은 무엇인가?

-> double

2. 다음에서 pt에 저장될 주소의 자료형은 무엇인가?

-> double *

3. 다음에서 pt의 자료형은 무엇인가?

-> double*

4. 다음처럼 포인터를 선언할 때 double의 의미를 설명하라.

-> 포인터 선언 시 자료형은 주소가 가리키는 공간에 저장된 데이터의 자료형을 의미하므로 다음처럼 포인터를 선언할 때 double의 의미 또한 주소가 가리키는 공간에 저장된 자료형을 의미한다.

5. 포인터 변수 pt가 메모리에 할당될 때 메모리 크기는?

-> 32비트 시스템에서는 4바이트에 할당되고 64비트 시스템에서는 8바이트에 할당된다.

# 실습과제 4 소스코드 설명
```
#include<stdio.h>
```
- 헤더파일 stdio.h를 포함해라
```
int main(void)
```
- 메인함수 시작
```
char a = 'A';
```
- char형 변수 a를 선언하고 'A'를 저장
```
int b = 36;
```
- int형 변수 b를 선언하고 36을 저장
```
double c = 3.141592;
```
- double형 변수 c를 선언하고 3.141592를 저장
```
printf("char형 변수 a의 주소: %u\n", &a);
```
- 화면에 char형 변수 a의 주소를 출력해라
```
printf("int형 변수 b의 주소: %u\n", &b);
```
- 화면에 int형 변수 b의 주소를 출력해라
```
printf("double형 변수 c의 주소: %u", &c);
```
- 화면에 double형 변수 c의 주소를 출력해라
```
return 0;
```
- 0을 반환하고 메인함수 종료
