# 실습과제 1
1. 구조체가 필요한 이유를 설명하라
- 구조체란 서로 다른 종류의 데이터들을 모아서 만든 새로운 자료형으로 관련된 데이터를 하나로 묶어서 취급하면 사용과 관리가 매우 편리하기 때문이다
2. 배열과의 공통점과 차이점을 설명하라
- 공통점: 연속적 공간에 할당, 중괄호 안에 원소를 순서대로 나열
- 차이점: 배열의 경우에는 같은 종류의 데이터들의 집합이고 구조체의 경우 다른(다양한) 종류의 데이터들의 집합이다
3. 기본자료형과 구조체의 차이를 설명하라
- 기본자료형의 경우 c언어에서 이미 정의된 자료형이고 구조체는 사용자가 직접 정의하는 자료형이다
4. 구조체의 정의와 구조체 변수 선언의 의미를 각각 설명하라
- 구조체의 정의: 사용자가 새로운 자료형을 정의하는 일
- 구조체 변수의 선언: 구조체의 멤버 변수가 메모리 공간에 할당되는 것
