# 실습과제 1
## 프로그램 개발과정
1. 편집
- 사용자가 C언어로 소스파일을 작성하는 단계로 에디터(Editor)를 사용하여 작성하며 확장자가 .c인 소스파일이 만들어진다.
2. 선행처리
- 소스파일에 헤더파일을 포함시키거나 일부 문장을 다른 문장으로 바꾸는 작업 등 특별한 작업을 수행한다. 
3. 컴파일
- 컴파일러(Compiler)를 이용하여 소스파일을 목적파일로 변역하는 단계로 확장자가 .obj인 목적파일이 만들어진다. 
4. 링크
- 링커(Linker)를 이용하여 여러 개의 목적파일을 하나의 실행파일로 만드는 과정으로 확장자가 .exe인 실행파일이 만들어진다. 
5. 실행
- 로더(loader)로 실행파일을 주기억장치(RAM)로 로드하고 실행을 한다.
