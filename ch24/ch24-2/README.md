# 실습과제 4
<20페이지 예제4-1의 실행결과를 자세히 설명하시오.>
- `%s`는 공백 문자를 문자열의 끝으로 판단하여 공백 이전까지만 출력하고 `%c`는 공백 문자를 저장한다. `%d`는 숫자를 입력받거나 출력하는데 `%c`앞에 공백이 없으면 해당 공백을 gender에 저장하기 때문에 `%d`에는 저장할 숫자가 존재하지 않게 되면서 초기값인 쓰레기값이 출력이 된다. 두번째는 M을 name에 공백을 gender에 23을 age로 저장하여 출력하게 되며 이후부터는 위 과정이 반복되게 된다.
